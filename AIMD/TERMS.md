## 🔤 Core Glossary A-Z
<a id="a-coreglossaryaz"></a>[TOC](#toc-coreglossaryaz)

### Action Verb
<a id="a-actionverb"></a>[TOC](#toc-actionverb)
- **Definition:** The operations dispatched onto a calculated set of document matches, driving specific IDE mutations or mutations to the system environment.
- **Code Implementation Context:** Handled within the `executeVerb` matrix block using parameters like `browse`, `next`, `prev`, `copy`, and `inject`.
- **Synonyms / Avoid:** Avoid: *command mutation*, *execution handle*, *macro tool*.

### Context Tracer
<a id="a-contexttracer"></a>[TOC](#toc-contexttracer)
- **Definition:** The operational sub-system responsible for mapping the hierarchical structural location of a document substring by traversing header configurations line-by-line backwards toward the root.
- **Code Implementation Context:** Managed explicitly within the `getMarkdownContexts` functional logic layer.
- **Synonyms / Avoid:** Avoid: *line spider*, *upward header looker*, *structural crawler*.

### Narrowest Container
<a id="a-narrowestcontainer"></a>[TOC](#toc-narrowestcontainer)
- **Definition:** The smallest bounding character pair sequence surrounding the precise character coordinate index of an active text editor cursor selection.
- **Code Implementation Context:** Calculated inside the `getExtractors` extraction loop using character balance loops and length minimization logic tracking `narrowestLength`.
- **Synonyms / Avoid:** Avoid: *closest quote*, *inner wrapper*, *bracket grabber*.

### Positional Token
<a id="a-positionaltoken"></a>[TOC](#toc-positionaltoken)
- **Definition:** An isolated string component pulled programmatically from an active user text line base based on cursor coordinates, divided into multiple scope layers.
- **Code Implementation Context:** Evaluated and returned as a grouped structural payload object by the `getExtractors` framework routine.
- **Synonyms / Avoid:** Avoid: *cursor text chunk*, *hover fragment*.
